# Examples

A small **synthetic** example pair is bundled here so you can run the pipeline
immediately:

- `audio/reference.wav` — a short C-major arpeggio "performance".
- `audio/candidate.wav` — a "transcription" of it with realistic errors (onset
  jitter, altered durations, and one wrong pitch a semitone off).

These files are synthetic (generated by `make_example_audio.py`), not ATEPP, and
do not reproduce any paper number — real reference/rendered audio is not
redistributed (see [../ETHICS_AND_DATA_GOVERNANCE.md](../ETHICS_AND_DATA_GOVERNANCE.md)).
Regenerate them with `python examples/make_example_audio.py`.

## Quick start

```bash
pip install -e .
```

### Single feature (lower score = more similar)

```bash
# DTW, default feature (tempogram)
python -m amt_dual_eval.cli audio-score --metric dtw --feature tempogram \
  --reference examples/audio/reference.wav \
  --candidate examples/audio/candidate.wav
# -> dtw_score: 0.188049  (feature=tempogram)

# TWED, default feature (mfcc), defaults nu=0.001 lambda=2.0
python -m amt_dual_eval.cli audio-score --metric twed --feature mfcc \
  --reference examples/audio/reference.wav \
  --candidate examples/audio/candidate.wav
# -> twed_score: 0.097557  (feature=mfcc)
```

### Sanity check: identical audio scores ≈0

```bash
python -m amt_dual_eval.cli audio-score --metric dtw --feature tempogram \
  --reference examples/audio/reference.wav \
  --candidate examples/audio/reference.wav
# -> dtw_score: 0.000000  (feature=tempogram)
```

### All verified top-3 features

```bash
python -m amt_dual_eval.cli audio-score --metric dtw --all-top3 \
  --reference examples/audio/reference.wav \
  --candidate examples/audio/candidate.wav
# feature      metric  score
# tempogram    dtw    0.188049
# chroma_cens  dtw    0.094094
# chroma       dtw    0.096219

python -m amt_dual_eval.cli audio-score --metric twed --all-top3 \
  --reference examples/audio/reference.wav \
  --candidate examples/audio/candidate.wav \
  --output-format json
```

### Use your own audio

Pass any reference/candidate paths (any format librosa can read) to the CLI shown
above. ATEPP and rendered audio are not redistributed here.
